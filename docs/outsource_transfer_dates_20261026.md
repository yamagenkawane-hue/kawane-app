# 進捗画面から外注日程登録・工程移動（2026-10-26）

## 仕様

- 外注加工の工程で「次工程へ移動」を押し、出し日・戻り予定日・戻り実績日のいずれかが未登録なら、3日程と移動数量を入力するダイアログを表示する。
- 登録済み日付は初期表示して読み取り専用にする。未登録の日付を当日で自動補完しない。
- 「登録して次工程へ移動」で、外注日程保存・外注ステータス更新・数量移動・実績記録を一括実行する。作業日には戻り実績日を使う。
- すべての日程が登録済みなら入力画面を省略し、既存の数量・移動確認から処理する。この場合も作業日は登録済み戻り実績日を使う。
- 外注以外の工程は既存の数量・作業日入力を継続する。
- 外注判定は外注先の登録、工程マスターの外注区分、既存の外注・メッキ工程名に対応する。
- 予定日・実績日は出し日以降とする。出し日・実績日は本日以前、予定日は未来の日付も許可する。予定日より早い／遅い戻りも登録可能。
- 入力をキャンセルした場合は日程も数量も変えない。移動に失敗した場合は日程保存もロールバックする。同一キー再送による二重移動を防ぐ。
- 入力中に別の操作で日程が保存された場合は、既存値と異なる日付への上書きを拒否して再読み込みを案内する。

## 実装

- `app/components/OutsourceTransferDialog/`: 日程・数量入力。保存中の重複操作防止、エラー表示、キャンセル。
- `lib/outsourceTransfer.ts`: 外注工程判定と日付検証。
- `app/reservation/page.tsx`: 操作時に最新の日程を取得して入力画面へ接続。
- `supabase/migrations/20261026_outsource_dates_and_transfer.sql`: `transfer_outsource_lot_with_dates` を追加し、既存の作業日対応工程移動関数をトランザクション内で利用。外注日程画面と同じ `order_processes` の日程カラムへ保存。

2. 出し日・予定日・実績日と移動数量を入力する。
