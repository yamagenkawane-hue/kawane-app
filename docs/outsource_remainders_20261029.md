# 外注残数の分割日程管理（2026-10-29）

## requirements

残数を複数回に分けて外注へ出す運用に対応する。追加するたびに対象数量、出し日、予定日、実績日、メモを登録する。初回の日程は保持する。ユーザーより分割回数が複数になることを確認済み。

## design / implementation

- 外注管理の初回日程の下に「残数の日程を追加」を配置。追加分を番号付きで識別する。
- `outsource_remainder_schedules` に工程単位で追加日程を保存。数量・移動済み数量・各日程・取消状態・更新日時を管理する。
- 予約済みの未移動数量を残数から差し引き、重複予約と数量超過をDBでも禁止する。
- 追加番号は取消後も再利用しない。取消は履歴を残す論理取消とする。
- 日程未確定時は空欄保存可能。次工程移動時は3日程が必須で、該当便の実績日を工程実績日に使う。
- 複数便から対象便を選択して移動する。部分移動の未移動残は元工程に残す。
- 移動済みの便の日程変更・取消は不可。更新競合、二重実行、ロック工程をDBで検査する。
- 新規テーブルの直接書き込みは禁止し、既存アプリと同じロールに検証付きRPCの実行を許可する。
