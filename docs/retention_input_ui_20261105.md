# 履歴管理マスタの入力UI（2026-11-05）

- 業務詳細履歴の保存年数、AI用実績の保存年数、AI予測記録の保存日数を共通Numpadで編集できるようにする。
- 数値欄のクリック・フォーカスで現在値を表示する。最初の数字入力で現在値を置換する。閉じて開き直した場合も置換する。
- テンキーでは整数のみ受け付け、既存のmin/max/requiredとサーバー側検証を維持する。設定を保存するまではサーバーを更新しない。
- 共通テンキーを画面固有のmain要素の外に配置し、履歴管理画面のボタン装飾でキーの見た目が上書きされないようにする。
- 退避ファイル選択欄は、ホバー時に手のカーソル・青い枠・背景の変化で選択可能と分かるようにする。キーボードフォーカスも強調し、処理中は無効カーソルと薄い表示にする。
- ファイル種別制限・16MB制限・読み込んだファイルの検証・削除/復元時の確認文入力は変更しない。
