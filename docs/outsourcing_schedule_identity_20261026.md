# 外注管理の日程識別表示（2026-10-26）

- 進捗画面から注番を指定して開いた場合も、各行に工程番号・工程名・外注先を表示する。従来はこの表示が省略され、上部に複数工程・外注先をまとめて表示していたため、日程行との対応が分からなかった。
- 上部は納期・注番・得意先・製品の共通情報に整理。工程・外注先は日程と同じ行へ表示する。
- 日程入力欄の上にも「第N工程：工程名／外注先」を表示し、横スクロール時にも識別可能にする。
- 日付欄の名前も注番・工程番号・工程名・外注先・日付の種類を含め、同じ工程名や同じ外注先が続く場合でも区別する。
- 外注先未登録時は「外注先未設定」と明示する。
- 注番指定画面の列数・列幅と横スクロールを調整。
- 2つの工程・外注先・異なる日付を持つ表示を、注番指定あり／なしの両方で検証。各行の日程が混ざらないことを含め、既存と合わせてオフライン検証80項目成功。
- 表示の変更のみで、保存処理・DBの変更は不要。

動作確認先はローカルの外注管理画面。本番公開アプリへのデプロイは未実施。
