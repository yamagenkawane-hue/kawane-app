# 外注管理の出荷件数（2026-11-02）

前回の得意先への製品出荷による集計は解釈違いのため廃止し、外注先への発送として訂正する。

- 表示中の外注工程ごとに、出し日（outsource_sent_date）があれば出荷済み、なければ未出荷。
- 同じ注番でも外注工程が複数あれば別々に判定。戻り済みでも出し日があれば出荷済み。
- 空文字・null・空白は未登録として扱う。
- 完了済みも表示の切替後も、表示中の一覧と一致する件数を表示する。
- 表示件数＝出荷済み件数＋未出荷件数。工程単位・出し日あり／なしをカードに併記。
- 出し日の保存後は再取得して再集計する。

不要になった受注・製品出荷履歴の取得を削除。DB変更・業務データ更新なし。
同一注番の連続外注工程、空の日付、戻り済み、空一覧の回帰テストとTypeScript・ESLint・本番ビルドで確認する。
