# 外注管理の出荷件数（2026-11-02）

「完了工程」の集計カードを削除し、「出荷済み件数」「未出荷件数」を追加した。

- 外注対象の有効な注番を1件として数える。同一注番に外注工程・外注先が複数あっても重複しない。
- 取消されていない出荷数の合計が受注数以上になった注番は出荷済み。未出荷・分納中は未出荷に含める。
- 取消済み出荷、削除済み受注、外注対象外の受注は集計しない。旧出荷でpost_idがない場合は注番で照合する。
- 「完了済みも表示」は一覧の表示条件として維持する。出荷件数はこのチェックにかかわらず外注対象全体を集計する。
- 「表示件数」は従来どおり表示中の工程数。出荷の件数は注番単位であることを各カードに併記する。

実装: `lib/outsourceShipmentSummary.ts`と外注管理画面。受注・有効出荷・工程をページ分割取得し、Supabaseの既定行数上限で集計が欠けないようにした。DB変更・業務データ更新なし。

検証: 画面・ロジックのテスト131件、TypeScript・ESLint・本番ビルドを確認。確認時点の実データは外注対象14注番、出荷済み2件、未出荷12件。別のSQL集計とローカル画面の値が一致した。完了済みの表示切替で一覧の工程数が6→16になっても、出荷件数2・未出荷件数12が変わらないことを確認した。
