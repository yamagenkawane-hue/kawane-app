# 進捗管理の取引先順（2026-11-02）

## requirements / design

取引先名の表記比較では漢字名を読みの五十音順にできないため、得意先マスターに`customer_name_kana`を追加し、進捗管理の第一ソート条件とする。ユーザー指示により、英語表記はアルファベット順とする。

- 英字で始まる取引先名はA→Z。大文字小文字と全角英字の違いを吸収する。
- 日本語名はマスターのふりがなで比較。ひらがな・カタカナ・半角カタカナを正規化する。
- 英字名、日本語名、読み未登録の漢字名、空の名前の順に配置する。
- 同じ取引先内の製品名・製品コード・納期・注番の比較とグループ表示は従来どおり。
- 漢字名を新規登録・保存する場合はふりがなを必須とする。英字名やかなだけの名称は省略可能。

## implementation

- `lib/customerSort.ts`: 比較・読みの正規化・入力検証。
- `app/customerMaster/page.tsx`: 追加・編集欄と一覧にふりがなを追加。
- `app/utills/useFetchPosts.tsx`: customer_idを使ってマスターの読みを受注へ対応付ける。旧データでは取引先名でも照合する。
- `app/reservation/page.tsx`: 読みに基づく比較を適用。
- `20261102060311_customer_name_reading.sql`: 読み列を追加。既存の認証・RLSは維持する。

本番DBの読み列追加と、今回のテスト5件に対応する読みは反映済み。対象は川根サンプル工業、グループ表示テスト工業、テスト工業、テスト製作所、デモ工業。
