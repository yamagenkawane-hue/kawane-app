# 注番管理の出荷状況・表示順

## 要件と実装

- 「全て・未出荷・一部出荷・完了」で絞り込む。初期表示は全て。
- 受注ID単位で有効な出荷数量を集計し、複数ロットでも同じ出荷状況を使う。
- 未出荷は出荷合計0、一部出荷は出荷合計が受注数量未満、完了は完納または打ち切り済み。
- 出荷取消済みは数量・登録日の集計から除く。
- 出荷の登録日時が新しい順に並べる。未出荷は下にまとめ、納期が近い順にする。
- 同じ日時・納期は注番、ロットIDの順で安定させる。
- 一覧に最終出荷日を表示し、納品日・出荷予定日を並べ替えに代用しない。
- 登録日時は一覧と履歴で日本時間の年月日に統一し、UTC深夜境界で前日にならないようにする。
- 注番のみで紐づく旧出荷は、同じ注番の受注が1件の場合だけ集計する。
- 検索と絞り込みを併用し、条件変更で1ページ目に戻す。30件表示を維持。
- 全件取得をページ分割し、RESTの1000件上限による集計漏れを防ぐ。
- データ取得に失敗した場合は誤った出荷状況を生成せず、再読み込みを案内する。
