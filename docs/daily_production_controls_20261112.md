# デイリー生産予定の製造画面・検索・受注別計画数

## 要件と実装

- 製造G画面の受注自動表示行、生産予定行の両方から編集・削除ボタンと操作列を除去。画面から予定を削除したり、受注の対象期間を解除したりする処理も除去した。数量・日付の表示は維持する。
- 検索欄と検索ボタンを「全て」画面へ移動。全体一覧に検索を適用し、製造Gへ切り替えたときは全体検索の条件で製造行を隠さない。プレス機Noの検索は同じ受注に紐づく予定を参照する。
- 「全て」の編集で計画数を入力できるようにし、電卓入力も利用可能にする。0は有効な数として保存・表示する。未入力・負数・小数・整数上限超過は保存を拒否する。
- ユーザー確認により、計画数はその受注だけの設定とする。製品マスタの計画数を初期値に使い、編集後は受注の製造予定に保存した値を優先する。製品マスタ、受注数、製造実績数、同じ製品の他受注は変更しない。
- 計画数と3部署の日程は単一トランザクションで保存する。日程だけを保存する旧クライアントからの呼出しは引き続き可能で、既存の受注別計画数を上書きしない。

受注別計画数は`production_schedules.production_plan_amount`へ保存。未設定はNULLであり製品マスタ値へフォールバックする。製造予定がない受注は計画数だけでも予定行を作成するが、作業日や実績数量を補完しない。複数予定がある場合は既存の日程保存と同様、最新の製造Gの予定行を受注代表として使う。

SQL：`20261112111343_per_order_production_plan.sql`。日程保存関数を任意の計画数引数付きへ置き換え、ビューの計画数を受注別設定優先にする。APIの4引数呼出しはデフォルト値で互換性を維持する。受注や履歴を削除するSQLはない。
