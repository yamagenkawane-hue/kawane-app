# 出荷管理の数量入力（2026-11-04・仕様訂正）

利用者の指示により、fb6513cで追加した数量列・残数プレビュー・個別エラー・登録直前の再取得を取り消し、以前の出荷管理画面と登録処理に戻す。

残す変更：
- 出荷入力枠は約半分の幅。50%、最小110px、最大140px。
- 入力初期値は注残数と出荷可能在庫の少ない方。既存v_shipping_candidates.available_quantityを利用する。他受注の引当分は除外される。
- 利用者が変更した数を優先し、空欄・0は勝手に初期値に戻さない。
- テンキーにも初期値を渡し、最初の数字入力で置換する。
- 出荷成功後は旧入力を解除し、再取得した最新の上限を初期表示する。
- 入力と実際の送信に同じ数量を利用する。
- DB変更なし。既存の出荷時数量チェック・原子的登録・冪等キーを維持する。
