# 在庫マスタのゼロ在庫・全数引当済み行の非表示（2026-11-05）

## 確定仕様

ユーザー確認により、現在庫数だけでなく「引当可能数＝現在庫数－引当済数」が0以下の行を在庫マスタの一覧から非表示にする。

出荷取消後に現在庫が戻り、引当可能数が正になれば、一覧を再取得したときに自動で再表示する。取消後も現在庫100・引当100のように全数引当済みであれば、非表示を継続する。

在庫の元レコード・ロット・引当・出荷移動明細は保持し、既存の出荷取消と打ち切り復元が元の在庫へ正しく戻せるようにする。自動の物理削除やDB変更は行わない。製品が同じでも、引当可能数がある異なるロットはそれぞれ表示する。

## 実装

lib/inventoryVisibility.tsで数量と表示条件を統一する。初回読取と保存・追加・削除後の読取で同じ条件を適用する。編集中の行が数量を0に入力した瞬間に消えないよう、表示条件はデータ取得時に適用する。

既存の1000件の読取上限によって後続の在庫が隠れないよう、fetchAllRowsで更新日時・IDを安定した順に全件取得する。

- verify-inventory-visibility-db.mjs：64件成功（既存55件を含む）。実際の出荷・出荷取消・引当確定を隔離DBで実行し、在庫復元と表示条件を検証する。
- verify-live-inventory-visibility.mjs：実DBの在庫ビューをログイン権限で読み取り、条件による表示を確認。業務データ書込なし。
- DB構造変更・実在庫削除・本番受注の出荷や取消試験は行わない。
