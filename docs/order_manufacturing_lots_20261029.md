# 注残管理の製造確定ロット表示（2026-10-29）

## requirements / design

注残管理のロットNo欄は受注入力の単一ロット番号ではなく、製造実績に紐づいたロットを表示する。同じ注番の複数ロットに対応し、受注行は増やさずロット欄内に列挙する。

製造実績確定RPC `register_manufacturing_lot_result` は先頭工程の正数実績をロットID付きで保存する。この関係を参照し、予定だけのロットや後続工程実績のみのロットは対象としない。削除済みロットを除外し、同一ロットで実績登録を繰り返しても重複表示しない。材料ロットを併記して同名ロットを識別できるようにする。

## implementation

- `lib/orderManufacturingLots.ts`: 注番ごとの先頭工程と正数の製造実績から確定ロットを抽出する。注番の所属不一致を除外し、ロットID単位で重複排除する。
- `app/orders/page.tsx`: 実ロットとロット付き実績をページ分割取得し、複数ロットを表示。各ロットから履歴に移動できる。
- ロット欄は実績に基づく参照欄とし、受注編集時の単一ロット入力を廃止。受注保存時に `posts.lot_no` を更新しない。
- DB変更なし。既存の受注数、完成数、注残、在庫引当、出荷計算は変更しない。
